Abrí `index.html` en el navegador para recorrer la galería y abrir cada slide.

## Orden sugerido para presentar

1. Portada
2. Mapa de ceremonias
3. El Sprint como contenedor

5. Daily Scrum
6. Backlog Refinement
7. Sprint Review
8. Sprint Retrospective

## Notas

- Todas las slides incluyen el logo de Humber en la esquina superior izquierda.
- La paleta visual respeta tonos anaranjados, negro/grafito y fondos claros inspirados en la marca.
- El formato de entrega principal es SVG para mantener nitidez y permitir edición posterior.
